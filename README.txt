Bloom · 指尖花开
==================================================

用摄像头识别手势，让一朵工笔花在指尖开放。完整教程见 Tutorial.pdf。

快速开始
--------------------------------------------------
Mac：     双击 START-Mac.command
          （第一次如果提示“无法打开”：右键 → 打开 → 再点“打开”）
Windows： 双击 START-Windows.bat
          （如果提示“Windows 已保护你的电脑”：点“更多信息” → “仍要运行”）

浏览器会自动打开页面，点 Enable camera，允许使用摄像头，把手举到镜头前。
不要直接双击 index.html，浏览器不允许本地文件加载识别模型。

手势
--------------------------------------------------
两指    拇指和食指张开 / 捏合（其余三指收起）   花慢慢开 / 合
数指    伸出 0～5 根手指                        开到第几级
五指    五根手指全部张开                        全盛，花瓣飘落；转动手掌，花跟着转
挥手    横着快速一挥                            往右下一朵，往左上一朵
双手    两只手都入镜                            左右两朵花，各管各的

键盘
--------------------------------------------------
V  手机竖屏 9:16      H  隐藏摄像头上的面板（录屏用）
← →  换花            0～5  模拟数指      D  双花      鼠标拖动  转动花朵

文件
--------------------------------------------------
index.html                页面本体
lib/  models/             手势识别库和模型（本地离线）
frames/                   放你自己生成的花（见 frames/README.txt）
tools/make_frames.sh      视频 → 透明序列帧（Mac，需要 ffmpeg）
tools/key_paper.py        自动抠背景，make_frames.sh 会调用它
tools/serve.ps1           Windows 本地服务，START-Windows.bat 会调用它
prompts/                  生成开花视频的提示词、用 AI 复刻网页的提示词
NOTICE.txt                第三方组件与许可
